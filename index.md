# Introduction

GorillaLibrary is a master library meant to aid mod developers in various factors all around the games codebase.

Some notable feature include:
- **Custom gamemodes:** GorillaLibrary includes an easy way for mod developers to create custom gamemodes, familiar to those who made them using Utilla, with backwards compatibility with Utilla.
- **Easy networking:** A new channel system that any mod developers can use to easily network specific things inside of their mods.
- **Custom wardrobes:** Easily add things such as custom cosmetics or anything related to the wardrobes inside of the game in mods.
- **Easy game events:** GorillaLibrary provides a whole lot of events to subscribe to within your mods, these range from just the game initalizing to someone's colour changing.

# Installation
GorillaLibrary is avaliable via [MonkeForge](https://monkeforge.org/view/gorillalibrary) or [GitHub](https://github.com/GorillaTagModdingHub/GorillaLibrary/releases/latest), choose which one is easier for you,
(If you use MonkeForge, you can get easy updates via the MonkeForge app.)
