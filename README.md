# GorillaLibrary

GorillaLibrary is a master library meant to aid mod developers in various factors all around the games codebase.

Some notable feature include:
- **Custom gamemodes:** GorillaLibrary includes an easy way for mod developers to create custom gamemodes, familiar to those who made them using Utilla, with backwards compatibility with Utilla.
- **Easy networking:** A new channel system that any mod developers can use to easily network specific things inside of their mods.
- **Custom wardrobes:** Easily add things such as custom cosmetics or anything related to the wardrobes inside of the game in mods.
- **Easy game events:** GorillaLibrary provides a whole lot of events to subscribe to within your mods, these range from just the game initalizing to someone's colour changing.
- And a whole lot more including inputs, rig utilities, etc.

## FAQ

- Is this a replacement to Utilla?
  - Yes. It is, although both mods can work together, all Utilla game modes are automatically translated into GorillaLibrary game modes.
- Why use this over Utilla?
  - Utilla is pretty old, and it's shown. The only reason why any updates are made for it anymore is just to fix it for a new game update, and it's only really strong suit was making custom game modes. GorillaLibrary includes many utilities for mod developers to make mod creation easier on top of having the same game mode functionality as Utilla.
- How do I install it?
  - Go to the releases tab on the right bar of this page (on desktop) or install it from [MonkeForge](https://monkeforge.org/view/gorillalibrary)
- Is there documentation for mod developers?
  - Yes! It is available [here.](https://gorillatagmoddinghub.github.io/GorillaLibrary/index.html)
